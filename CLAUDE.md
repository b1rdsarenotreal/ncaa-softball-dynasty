# NCAA Softball Dynasty

A commissioner-style dynasty for the real NCAA Division I softball teams (300 programs, 31 conferences, 2026 start). It began as a copy of **SACAA Dynasty** ([b1rdsarenotreal/sacaa-dynasty](https://github.com/b1rdsarenotreal/sacaa-dynasty)), which is itself a twin of **MCS Dynasty** ([b1rdsarenotreal/mcs-dyansty](https://github.com/b1rdsarenotreal/mcs-dyansty)).

## Not synced with the twins

**Rule from the owner:** this app is kept separate. Changes made here do not go to MCS or SACAA, and changes there don't come here, unless the owner asks for that specific change. If the owner does ask to port something, port the edit itself (not whole files, since version stamps differ), then run `python3 tools/stamp.py` in each repo.

What differs from SACAA on purpose:

| | |
|---|---|
| Teams, conferences, coaches, colors, ratings | `js/data.js`, generated by `python3 tools/build_data.py data/ratings.csv data/teams.txt > head.js` (replace everything above `makeTeam` with its output) |
| Start year | 2026 |
| Championship name | Women's College World Series (WCWS) at Devon Park, Oklahoma City |
| Default NCAA format | 64 teams: 16 four-team regionals, 8 super regionals, 8-team WCWS |
| Default poll | Top 25 |
| Save and logo-cache keys | `ncaa-softball-dynasty`, `ncaa-softball-logo-table-v1` |
| Scale changes for 300 teams | `simGames` plays each time slot as one batch; the NCAA format editor requires room for every automatic bid; the hot seat never suggests firing a coach after one season |

## Before every commit

- `python3 tools/stamp.py`
- `sh tools/check.sh`
- `node tests/logic.test.mjs` (about two minutes at 300 teams)
- `python3 tests/ui_test.py` (Playwright; Chromium is preinstalled)
